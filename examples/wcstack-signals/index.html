@wcstack/signals + <ami-voice>

A buildless, signals-based reactive core driving real DOM with h(), consuming the <ami-voice> element through the wc-bindable adapter: bindNode() turns its reactive properties into read-only signals; command() drives start / stop / reset. File recognition is the same story — bindNode() over a <wcs-fetch> element turns its value / loading / error into signals.
