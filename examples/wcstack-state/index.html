@wcstack/state + <ami-voice>

No build, no framework. <wcs-state> binds the <ami-voice> element's reactive state to the DOM with data-wcs path strings, and drives its start / stop / reset commands via command tokens. File recognition is fully declarative too: <wcs-fetch> owns the /api/recognize POST and its value / loading / error bind back into state.

@wcstack/state <ami-voice> <wcs-fetch> buildless

Realtime (relay)

Allow the microphone when prompted. Chrome recommended.

File recognition

Posts the file to /api/recognize via <wcs-fetch> (server-side recognition).
